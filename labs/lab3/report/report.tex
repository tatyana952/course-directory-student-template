\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  В установленной операционной системе создаю учётную запись поль-
  зователя guest (использую учётную запись администратора): useradd
  guest
\item
  Задаю пароль для пользователя guest (использую учётную запись ад-
  министратора): passwd guest
\item
  Аналогично создаю второго пользователя guest2.
\item
  Добавляю пользователя guest2 в группу guest: gpasswd -a guest2 guest
\item
  Осуществляю вход в систему от двух пользователей на двух разных кон-
  солях: guest на первой консоли и guest2 на второй консоли.
\item
  Для обоих пользователей командой pwd определяю директорию, в кото- рой
  вы находитесь. Сравниваю её с приглашениями командной строки.
\item
  Уточняю имя вашего пользователя, его группу, кто входит в неё и к
  каким группам принадлежит он сам. Определяю командами groups guest и
  groups guest2, в какие группы входят пользовате- ли guest и guest2.
  Сравните вывод команды groups с выводом команд id -Gn и id -G.
\item
  Сравниваю полученную информацию с содержимым файла /etc/group.
  Просмотрите файл командой cat /etc/group
\item
  От имени пользователя guest2 выполняю регистрацию пользователя guest2
  в группе guest командой newgrp guest
\item
  От имени пользователя guest изменяю права директории /home/guest,
  разрешив все действия для пользователей группы: chmod g+rwx
  /home/guest
\item
  От имени пользователя guest снимаю с директории /home/guest/dir1 все
  атрибуты командой
\end{enumerate}
